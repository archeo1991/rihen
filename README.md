# 日痕

日痕是一个极简的生命天数工具。输入生日后，它只显示你已经活了多少天；在一些特殊的日子，例如第 `1111` 天、第 `1234` 天，会通过安卓本地通知提醒你。

这个仓库目前包含安卓应用安装包、安卓桌面小组件与源码。

## 安卓应用

安卓项目在 `android/` 目录中。已经生成的安装包在仓库根目录：

- 正式版：`Rihen-release.apk`

安装后，应用名为「日痕」。首次进入应用时设置生日，之后主界面会显示已活天数。生日选择器支持直接选择年、月、日，不需要一月一月翻日历。

当前包名为 `cn.archeo.rihen`。如果手机上安装过旧包名版本，需要手动卸载旧版，或与新版并存安装。

## 安卓桌面小组件

安装「日痕」后，可以在安卓桌面的小组件列表中添加「日痕」组件。小组件会显示“人间第 N 天”。未设置生日时，小组件显示 `--`，并提示点击设置。

点击桌面小组件会打开应用，方便修改生日。生日保存或修改后，桌面小组件会同步刷新；手机重启、日期变化、系统时间或时区变化后，也会重新刷新和安排提醒。

## 特殊日子提醒

安卓版本会为未来的特殊天数安排本地提醒，例如：

- `1111` 天
- `1234` 天
- `2222` 天
- `3333` 天
- `9999` 天
- `10000` 天

提醒默认安排在特殊日当天本地时间 09:00。安卓 13 及以上系统会请求通知权限；如果没有授权，应用仍可正常显示天数，只是不会发送提醒。

为了尽量准时提醒，应用会请求精确闹钟权限。如果系统或厂商省电策略限制后台任务，提醒可能仍会延迟；应用内会在需要时显示“开启准时提醒”入口。

## 特殊日分享

当今天正好是特殊天数时，主界面会出现“分享这一天”按钮，当天的提醒里也会提供同一个入口。点击后会生成一张 `1080 × 1440` 的分享卡片，包含：

- “人间第 N 天”
- 当天日期
- 与该里程碑对应的一句古诗词及出处

卡片会直接交给安卓系统分享面板，不会写入相册，也不需要在应用里保存。分享图片只暂存在应用缓存中，七天后会自动清理。

## 重新构建 Android 安装包

如果需要重新构建 APK，可以打开 `android/` 目录使用 Android Studio 构建。当前仓库也保留了一套项目内构建工具在 `.build-tools/`，已用于生成当前安装包。

正式包使用 `android/app/release/rihen-release.jks` 签名。这个签名文件必须保留好，之后发布更新需要继续使用同一个 keystore。
