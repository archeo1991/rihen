# 日痕

日痕是一个极简的生命天数小工具。输入生日后，它只显示你已经活了多少天；在一些特殊的日子，例如第 `1111` 天、第 `1234` 天，会通过安卓本地通知提醒你。

这个仓库目前包含两个版本：

- Windows 桌面小挂件
- 安卓应用安装包、桌面小组件与源码

## Windows 桌面小挂件

双击 `StartLifeDaysWidget.vbs` 启动。

首次打开时选择生日并保存。保存后，生日编辑区会收起，窗口只显示已活天数。之后可以点击小小的 `...` 按钮修改生日。

桌面小挂件会置顶显示，可以拖动顶部区域移动窗口，也可以点击右上角 `x` 关闭。生日只保存在本机：

`%APPDATA%\LifeDaysWidget\birthday.txt`

## 安卓应用

安卓项目在 `android/` 目录中。已经生成的调试安装包在仓库根目录：

`LifeDays-debug.apk`

安装后，应用名为「日痕」。首次进入应用时设置生日，之后主界面会显示已活天数。生日选择器支持直接选择年、月、日，不需要一月一月翻日历。

## 安卓桌面小组件

安装「日痕」后，可以在安卓桌面的小组件列表中添加「日痕」组件。小组件会直接显示“我存在了多少天”，未设置生日时会提示点击设置生日。

点击桌面小组件会打开应用，方便修改生日。生日保存或修改后，桌面小组件会同步刷新；手机重启后也会继续读取本机保存的生日。

## 特殊日子提醒

安卓版本会为未来的特殊天数安排本地提醒，例如：

- `1111` 天
- `1234` 天
- `2222` 天
- `3333` 天
- `9999` 天
- `10000` 天

提醒默认安排在特殊日当天本地时间 09:00。安卓 13 及以上系统会在设置生日后请求通知权限；如果没有授权，应用仍可正常显示天数，只是不会发送提醒。

## 重新构建 Android 安装包

如果需要重新构建 APK，可以打开 `android/` 目录使用 Android Studio 构建。当前仓库也保留了一套项目内构建工具在 `.build-tools/`，已用于生成当前的 `LifeDays-debug.apk`。

调试包使用 debug 签名，适合直接安装测试；如果要正式发布，需要再配置 release 签名。
