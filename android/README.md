# 日痕安卓版本

这是「日痕」的安卓版本。它会保存你的生日，显示你已经活了多少天，并在一些特殊的生命天数发送本地通知，例如第 `1111` 天、第 `1234` 天。

## 功能

- 设置或修改生日
- 显示已活天数
- 年 / 月 / 日三列滚轮选择生日
- 本地保存生日
- 安卓桌面小组件显示已存在天数
- 点击桌面小组件打开应用
- 在特殊天数发送本地通知
- 手机重启后自动重新安排未来提醒并刷新小组件

## 桌面小组件

安装应用后，在安卓桌面长按空白处，进入“小组件”列表，选择「日痕」添加到桌面。

小组件会显示应用名、已存在天数和“天”单位。未设置生日时，小组件显示 `--`，并提示点击设置生日。点击小组件会打开应用，设置或修改生日后小组件会立即刷新。

## 构建

可以用 Android Studio 打开当前 `android/` 目录，等待 Gradle 同步完成后运行 `app` 配置。

项目保持原生和轻量：

- 使用 Java 编写
- 界面由 `MainActivity` 动态创建
- 使用 `SharedPreferences` 保存生日
- 使用 `AppWidgetProvider` 提供桌面小组件
- 使用 `AlarmManager` 安排本地提醒
- 使用 `BroadcastReceiver` 接收提醒和开机事件

## 通知

安卓 13 及以上系统会请求通知权限。授权后，应用会为未来的特殊天数安排提醒，提醒时间为对应日期的本地时间 09:00。

当前特殊天数列表包含 `1111`、`1234`，以及一些整百、重复数字和纪念型天数。
